# 🍏 AION Cockpit - Progressive Web App (PWA)

ระบบควบคุมและตรวจสอบสถานะรถยนต์ไฟฟ้า AION สำหรับผู้ใช้งาน **iPhone (iOS)**, **iPad**, **คอมพิวเตอร์ (PC / Mac)**

---

## 🚀 ติดตั้งใช้งานบน Cloud ส่วนตัว (1-Click Deploy)
กดปุ่มด้านล่างเพื่อเปิดใช้งานเซิร์ฟเวอร์ส่วนตัวฟรีตลอด 24 ชั่วโมง ผ่านระบบ Cloud (Render.com):

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/VRmagician/aion-cockpit-pwa-releases)

---

### 📋 ขั้นตอนการติดตั้งใช้งานบน iPhone (iOS):
1. **กดปุ่ม `Deploy to Render` ด้านบน**
   * หากยังไม่มีบัญชี Render สามารถกด Sign up ฟรีด้วย Google หรือ GitHub ได้ทันที
2. **กดปุ่ม "Apply" หรือ "Create Web Service"**
   * ระบบ Render จะทำการสร้างเซิร์ฟเวอร์ส่วนตัวของคุณที่ศูนย์ข้อมูลสิงคโปร์ (ใช้เวลาประมาณ 1-2 นาที)
3. **เปิดใช้งานบน iPhone:**
   * เมื่อระบบสร้างเสร็จ คุณจะได้รับ URL เว็บส่วนตัว (เช่น `https://aion-cockpit-xxxx.onrender.com`)
   * นำลิงก์ไปเปิดในเบราว์เซอร์ **Safari** บน iPhone
   * กดปุ่มแชร์ (ไอคอนสี่เหลี่ยมลูกศรชี้ขึ้นที่แถบด้านล่างของ Safari)
   * เลือกเมนู **"เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)"**
4. **เปิดใช้งานแอป:**
   * ไอคอน AION Cockpit จะปรากฏบนหน้าจอโฮมของ iPhone สามารถกดเปิดใช้งานได้เต็มจอเสมือนแอปแท้ทันที!

### 🔒 ความปลอดภัยและความเป็นส่วนตัว (Privacy & Security)
* **ระบบความปลอดภัย Owner Gatekeeper:** หน้า Dashboard ได้รับการปกป้องด้วยระบบยืนยันตัวตนเจ้าของรถ หากบุคคลอื่นได้รับลิงก์ URL จะไม่สามารถดูสถานะรถ ข้อมูลแบตเตอรี่ แรงดันลมยาง หรือส่งคำสั่งใดๆ ได้ เว้นแต่จะระบุเบอร์มือถือหรืออีเมลที่ลงทะเบียนไว้กับบัญชีรถได้ถูกต้อง
* **ไม่มีเซิร์ฟเวอร์กลางเก็บข้อมูล:** ทุกคนมีเซิร์ฟเวอร์ส่วนตัวของตัวเอง ข้อมูลการล็อกอินและคำสั่งควบคุมรถจะสื่อสารตรงระหว่างอุปกรณ์ของคุณกับระบบ Cloud ของรถ AION เท่านั้น
* **ไม่มีค่าใช้จ่าย:** สามารถใช้งานบนโควต้า Free Tier ของ Render ได้ฟรีตลอดการใช้งาน
